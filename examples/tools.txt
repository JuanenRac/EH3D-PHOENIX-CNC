# The table of tools of the machine: for each tool number the name, the diameter and, if you wish, the length offset and the number of
# flutes of the tool that is meant to be in the spindle for it. The program reads it and, in --report and in the Statistics window, lists
# each tool a program takes with what the table says of it, and warns of a tool the table does not have. Nothing is sent to the machine.
#
# To use it, copy this file next to the settings file with the name phoenix-cnc-tools.txt and edit it. A line that is not valid is left
# out and named, with its number, in the report: a tool number from 1 to 255, a diameter above 0 up to 1000 mm, one line for each tool,
# up to 64 tools, a file of up to 16 KiB.
#
# tool = NUMBER | name=NAME | diameter=MM | length=MM | flutes=N      (the diameter is needed; the rest may be left out)
