# The library of materials: the range of cutting feed (mm per minute) and of spindle speed (rpm) that is a good place to start with each
# material, for small machines and small cutters. The program checks a G-code program against the material chosen in the settings (General
# checks section) and says when a cutting move runs below or above the feed range, or the spindle runs below or above the speed range.
# These are starting points, not rules: tune them to your cutter and your machine.
#
# To use your own library, copy this file next to the settings file with the name phoenix-cnc-materials.txt and edit it. While that file
# does not exist, this one is used.
#
